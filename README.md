## Deskripsi

Pada praktikum ini saya mempelajari dasar-dasar CSS (Cascading Style Sheets) dan cara menerapkannya pada halaman HTML.

Materi yang dipraktikkan meliputi:

- Internal CSS
- Inline CSS
- External CSS
- Element Selector
- ID Selector
- Class Selector

## Langkah Praktikum

### 1. Membuat File HTML

Membuat file `lab2_css_dasar.html` sebagai halaman utama untuk mempraktikkan CSS.

### 2. Internal CSS

CSS ditambahkan di dalam tag `<style>` yang berada pada bagian `<head>` HTML.

Contohnya digunakan untuk mengatur:

- Font
- Ukuran teks
- Warna teks
- Header
- Posisi teks

### 3. Inline CSS

Inline CSS diterapkan langsung pada elemen HTML menggunakan atribut `style`.
